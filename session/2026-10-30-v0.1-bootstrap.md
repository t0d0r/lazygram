# 2026-10-30 - v0.1 bootstrap

## Done

- Go module `lazygram` with bubbletea + lipgloss; own git repo.
- domain (merge/filter/resolve), store (JSONL cache), command parser, config
  validation, provider interface, demo provider, inert telegram provider,
  TUI (feed, history pager with live search, chat list, help), smoke mode.
- specs, README, todo, Makefile (help/build/test/lint/check/run/smoke/fmt/
  install/uninstall/clean).

## Decisions

- One merged feed is the default view (specs/overview.md).
- File-based JSONL cache instead of SQLite: no cgo or extra dependency, enough
  for v0.1; revisit when history gets large (todo).
- lint uses golangci-lint: the installed staticcheck binary was built with an
  older Go and cannot read the current standard library export data.
- Non-terminal stdin/stdout makes the binary print one screen and exit, so
  `make run` is safe in pipes and CI.
- Remote text is stripped of control characters at render time.
- Live Telegram is not implemented: no credentials or approved library exist.
  The seam is `telegram.Client`.
